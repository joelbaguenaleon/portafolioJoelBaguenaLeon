ChatbotNBA

Ver en GitHub

ChatbotNBA es una aplicación de escritorio dedicada a la consulta de información relacionada con la NBA. La aplicación permite realizar consultas sobre jugadores, equipos, partidos, clasificaciones y estadísticas mediante un sistema de chatbot. Este fue mi proyecto de fin de grado.

El proyecto utiliza Java Swing para gestionar la interfaz gráfica, Python y FastAPI para desarrollar el backend y SQLite para almacenar y consultar información. Además, utiliza una API externa para obtener datos relacionados con la NBA.

Tecnologías utilizadas

  • Java
  • Java Swing
  • Python
  • FastAPI
  • SQLite
  • SQL
  • API REST
  • JSON
  • PyInstaller
  • Launch4j

Funcionalidades principales

  • Consulta de jugadores de la NBA.
  • Consulta de equipos.
  • Consulta de partidos.
  • Consulta de clasificaciones.
  • Consulta de estadísticas.
  • Procesamiento de consultas mediante detección de palabras clave.
  • Comunicación entre la interfaz y el backend mediante API REST.
  • Almacenamiento de información mediante SQLite.
  • Obtención de información mediante una API externa.
  • Limpieza de la conversación.
  • Cierre del backend desde la aplicación.
  • Ejecución de la aplicación mediante un archivo .exe.

OnlineShop

Ver en GitHub

Online Shop es una aplicación web dedicada a la venta de productos de cuidado de la piel. La aplicación permite consultar productos, buscar por nombre, añadir productos al carrito y realizar pedidos. Los usuarios registrados pueden consultar su cuenta, ver el historial de pedidos y cancelar pedidos.

El proyecto utiliza Laravel para gestionar el backend, las vistas y la conexión con la base de datos, además de una API para gestionar usuarios, productos, categorías y pedidos.

Tecnologías utilizadas

  • PHP
  • Laravel
  • Blade
  • HTML5
  • CSS3
  • JavaScript
  • MySQL
  • API REST

Funcionalidades principales

  • Registro y login de usuarios.
  • Visualización y búsqueda de productos.
  • Carrito de compra.
  • Creación y almacenamiento de pedidos.
  • Historial y cancelación de pedidos.
  • Gestión de la cuenta de usuario.
  • Protección de rutas mediante autenticación.
  • Diseño de una página principal con vídeo e imágenes.

NBAguena

https://nbaguena.up.railway.app

Backend en GitHub

Frontend en GitHub

Como aficionado a la NBA que soy desde que comencé a seguirla siempre sentía que las webs de consulta de información eran algo confusas y incómodas de usar: formatos con estadísticas de jugadores en horizontal y webs demasiado complejas para hacer consultas simples. Debido a eso me propuse hacer una web sencilla para poder consultar información NBA usando los conocimientos adquiridos en anteriores proyectos.

NBAguena es una aplicación web dedicada a la consulta de información y estadísticas de la NBA. El proyecto permite consultar partidos, estadísticas de jugadores, comparar jugadores, clasificación y resultados. La web incluye un chatbot especializado para realizar consultas relacionadas con equipos, jugadores, partidos y clasificación. El chatbot reutiliza parte del código del proyecto ChatbotNBA mejorándolo en algunos aspectos.

El objetivo principal del proyecto ha sido desarrollar una aplicación full-stack, conectando diferentes tecnologías y servicios externos dentro de una arquitectura separada entre frontend y backend.
